# Bovision

Esse projeto foi desenvolvido para fins de detectar o comportamento de monta em bovinos, foi feito utilizando python e o modelo YOLOV8.

O arquivo BBD_1_0.ipynb contém o notebook utilizado para os testes, o modelo best.pt é o modelo final utilizado para a detecção.
